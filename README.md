Responsive Landing Page with Accessible Contact Form

Project: TechFest 2025 – Web Development Challenge
Submitted by: Gunjan Ghangare
Purpose: Single-page responsive landing page with an interactive tech stack and accessible contact flow.

Project Overview

This project is a mobile-first, professional landing page designed for the TechFest 2025. It demonstrates best practices in web design, accessibility, and front-end development. The landing page includes:

Responsive design: Works seamlessly across devices from 320px → 1440px.

Accessible contact form: Proper labels, ARIA attributes, and keyboard navigation.

Interactive tech stack section: Modern cards with technology logos, hover effects, and animations.

Professional UI/UX: Gradients, shadows, hover animations, and smooth transitions.

Client-side validation: JavaScript-based form validation with friendly error/success messages.

Deployment-ready: Can be deployed on platforms like Netlify or Vercel.

Features
1. Hero Section

Engaging headline and call-to-action button.

Gradient background with fade-in animation.

Button hover and focus effects for interactivity.

2. Tech Stack Section

Displays logos of technologies used (HTML, CSS, JavaScript, React, Node.js).

Responsive card grid with hover lift and icon rotation.

Gradient backgrounds and shadows for professional look.

3. Contact Form

Fully accessible with proper <label> and ARIA support.

Real-time validation for required fields and email format.

Success and error states with user-friendly messages.

Keyboard-friendly and screen-reader compatible.

4. Footer

Gradient matching header for visual consistency.

Clean layout with copyright information.

Technologies Used

HTML5 – Semantic markup

CSS3 – Flexbox, Grid, animations, gradients

JavaScript – Form validation, mock submission

DevIcons – Technology logos in features section

Accessibility & UX

Focus states visible for keyboard navigation.

Error messages use aria-live="polite" for screen readers.

Responsive grid layout ensures content is readable on all screen sizes.

Smooth scroll and animations enhance visual experience.
